# SocialHub – Social Media Application

A modern full-stack social media platform built with React, Node.js, Express, and MongoDB. Users can create posts, interact with content, and experience a responsive social networking interface.

## Live Demo

Frontend: https://social-app-kappa-pearl.vercel.app

## GitHub Repository

https://github.com/Azhanhashmi/social-app

---

## Features

* User Authentication
* Secure Login & Registration
* Create and Manage Posts
* Like and Comment Functionality
* Responsive Design
* Modern User Interface
* MongoDB Database Integration
* REST API Architecture
* Real-Time Social Feed Experience

## Installation

### Clone Repository

```bash
git clone https://github.com/Azhanhashmi/social-app.git
```

### Navigate to Project

```bash
cd social-app
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

---

## Environment Variables

Create a `.env` file and configure:

```env
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
PORT=5000
```
